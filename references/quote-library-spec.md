# 金句库规范

## 目标

保存少量、准确、可检索的短引用和传播化转述，用于文章开场、标题、转折、论证或结尾。金句库不是原文摘抄大全。

## 强制区分

- **原句摘录**：逐字核对的短摘录，可使用引号；必须有 S1 来源定位符。
- **传播化转述**：编辑者基于书中观点的改写；必须标“编辑改写/S3”，不得使用引号或写成“作者说”。

若无法逐字核对，只能进入传播化转述栏。

## 条目字段

| 字段 | 要求 |
| --- | --- |
| ID | `Q-001` 起连续编号 |
| 类型 | 洞察、悖论、警示、行动、比喻或定义 |
| 原句摘录 | 短、完整、不因截断改变原意；没有则写“无” |
| 传播化转述 | 可选；更适合标题或社交传播，但不得改变原命题 |
| 核心观点 | 对应概念或命题 ID |
| 情绪触发 | 惊讶、焦虑、希望、认同、冲突、反常识等 |
| 适用场景 | 标题、开场、转折、论据、结尾及适合的文章主题 |
| 语境与风险 | 限定条件、容易造成的误读、是否不宜脱离上下文引用 |
| 来源 | S1-S4 与来源定位符 |

## 选择标准

优先保留同时满足准确、简洁、张力、可迁移和可追溯的条目。删除只有口号感、依赖长上下文、重复表达同一观点或无法定位的候选。

A 路线建议 8-15 条高质量样例；B 路线通常 15-30 条，根据书的密度调整，不为数量牺牲质量。

## 版权边界

只摘取为评论、研究和说明所必要的短句，不连续复制多个相邻句子，不以金句库替代原书。对外成品优先使用自己的转述；原句引用保持克制并保留来源。

## 验收

随机抽查至少 5 条原句，与原 PDF 逐字比对；检查所有传播化转述都显式标记；检查每条都有语境风险与定位符。
